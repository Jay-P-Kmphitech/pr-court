# PR Court — Agents That Argue, Humans Decide

Two AI agents argue the case. A human rules. The team remembers.

Built on [Switch](https://switchagents.ai) for the Flip the Switch hackathon. Full README coming soon.

- `sample-app/` — demo multi-tenant orders API used for seeded PRs
- `decisions/` — generated `DEC-NNN.md` decision records
- `agents/`, `switch/`, `templates/` — agent instructions, room template, decision template
